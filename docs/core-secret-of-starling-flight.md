# 鸥椋鸟飞行核心秘密：关键少数与动态分组

## 一、核心洞察

鸥椋鸟群飞行不是"随机混乱"，而是由 **关键少数** 驱动的 **动态分组系统**：

```
随机数 = 关键少数 = 编队分组依据
```

**关键特性**：
- 关键少数从总数中按比例随机筛选（如千分之X）
- 关键少数内部有层级：1个领队 + 其他跟随者
- 编队根据关键少数数量动态分组
- 组内个体只做相对时空偏移，不做独立复杂计算

## 二、关键少数理论（精确版本）

### 2.1 定义与比例
- **关键少数**：从总数中按比例随机筛选的一组个体
- **比例计算**：千分之X，X根据飞行规模动态计算
  - 小规模（<1000只）：X较大，保证足够随机性
  - 中规模（1000-10000只）：X适中
  - 大规模（>10000只）：X较小，避免计算过载
- **示例**：
  - 200只鸟，千分之5 → 1个关键少数
  - 2000只鸟，千分之5 → 10个关键少数
  - 20000只鸟，千分之5 → 100个关键少数

### 2.2 关键少数的内部层级
关键少数不是平级的，而是有严格的层级结构：

```
领队（1个）
  ├── 关键少数A（跟随领队，2坐标锁定，1坐标自组织）
  ├── 关键少数B（跟随领队，2坐标锁定，1坐标自组织）
  ├── 关键少数C（跟随领队，2坐标锁定，1坐标自组织）
  └── ...
```

**领队特性**：
- 从关键少数中随机选择1个
- 飞行方向始终相同（或根据全局方向）
- 是编队的核心参考点

**其他关键少数特性**：
- 跟随领队飞行
- 在三个坐标中锁定2个坐标（与领队相同）
- 剩余1个坐标自组织（有限随机范围，如1-50厘米）
- 这种"2锁定+1自组织"产生类似太阳系的效果

### 2.3 关键少数与编组的关系
关键少数的数量直接决定编队的分组数量：

| 关键少数数量 | 编组数量 | 飞行行为 |
|-------------|---------|---------|
| 0 | 0 组 | 全部成员维持现有方向飞行，无分组 |
| 1 | 1 组 | 全部跟随唯一领队，维持现有方向 |
| 3 | 3 组 | 3个组，每组跟随各自领队飞行 |
| 12 | 12 组 | 12个组，每组跟随各自领队飞行 |

**关键规则**：
- 编组数量 = 关键少数数量（向下取整）
- 剩余成员（不能整除的余数）需要冗余分配到各组
- 每个关键少数成为该组的"领队"
- 组内其他个体跟随本组领队的方向

## 三、相对时空偏移

非关键少数个体不进行独立的方向计算，而是相对于本组领队进行：

1. **相对角度偏移**：基于领队方向 + 个体相对位置的角度修正
2. **相对距离偏移**：基于个体与领队的距离进行位置修正
3. **相对时间偏移**：基于距离领队的远近产生时间相位差

这种偏移全部简化为加减运算，避免复杂的三角函数、开方等。

## 五、关键算法约束（从梦境提取）

### 5.1 关键少数选择
```
1. 比例 K = 总数 / 1000 * X（X根据规模动态计算）
2. 时间间隔 T >= 2秒（变量），无固定规律
3. 从鸟群中随机选择 K 个个体作为关键少数
4. 从 K 个关键少数中随机选择 1 个作为领队
```

### 5.2 领队运动模型
```
1. 领队进行完整 Boids 计算
2. 领队方向 = 全局方向（或根据环境调整）
3. 其他关键少数跟随领队：
   - 锁定2个坐标（如 X, Y）与领队相同
   - 剩余1个坐标（Z）在有限范围内自组织（1-50厘米）
```

### 5.3 分组分配
```
1. 编组数量 = 关键少数数量（向下取整）
2. 每个关键少数成为1组的领队
3. 剩余成员按最近领队分配（Voronoi）
4. 不能整除的余数：冗余分配到各组（如轮询或随机）
```

### 5.4 组内运动
```
1. 领队：完整 Boids 计算，方向一致
2. 组员：相对本组领队的时空偏移
   - 相对位置偏移
   - 相对角度偏移
   - 相对时间偏移
3. 组间：弱交互（可选，避免完全分裂）
```

## 六、为什么这能产生"无穷变换有韵律的美感"

1. **随机性**：关键少数随时间随机变化，避免重复模式
2. **层级结构**：领队+跟随者产生清晰的指挥链
3. **太阳系模型**：2锁定+1自组织产生轨道般的运动
4. **动态分组**：不同分组数量产生不同的队形（1组=大球，12组=多簇）
5. **相对偏移**：组内个体相对于领队的位置/时间偏移，产生流动感
6. **三维空间**：Z轴深度叠加，视觉上形成复杂的立体队形

## 七、碰撞与重叠防护机制

### 7.1 跨组领队分离
不同组的领队之间施加轻量级分离力，防止异组鸟群在空间中穿模：
```go
groupSepRadius := p.SeparationRadius * 2.0
if distSq < groupSepRadius*groupSepRadius && distSq > 0 {
    force := (groupSepRadius - dist) / dist * 0.5
    ax += dx * force
    ay += dy * force
}
```

### 7.2 组内成员与领队分离
组员与领队之间保持最小距离，防止组内密集重叠：
```go
memberSepRadiusSq := p.SeparationRadius * p.SeparationRadius * 0.5
if distToLeaderSq < memberSepRadiusSq && distToLeaderSq > 0 {
    force := (sqrt(memberSepRadiusSq) - distToLeader) / distToLeader * 0.3
    ax -= diffX * force
    ay -= diffY * force
}
```

### 7.3 SelfOrgRange 联动约束
关键少数的自组织范围与 SeparationRadius 动态联动，避免关键少数偏离领队过远：
```go
if params.SelfOrgRange <= 0 {
    params.SelfOrgRange = params.SeparationRadius * 0.8
}
```

### 7.4 组级边界软约束
组中心接近画布边界时，施加额外的回拉力，防止整组鸟贴边后密集反弹：
```go
groupBoundaryMargin := p.BoundaryMargin * 1.5
if groupCenterX < groupBoundaryMargin {
    group.CenterX += (groupBoundaryMargin - groupCenterX) * 0.1
}
```
