# 欧椋鸟方程：群体动力学的神来之笔

> **重要说明**：本文档中的"场方程"（∇·Φ 等）是**启发性类比**，非严格数学推导。在离散 agent 系统中，Φ 是全局标量，∇ 无定义。严格推导见 `Starling-Theory-Rigorous-Derivation.md` 第 2-4 章。

## 摘要

本文提出了类似于麦克斯韦方程组的欧椋鸟方程，用最优雅的数学表达揭示了大规模群体行为的本质规律。这组方程简洁而深刻，堪称群体动力学的"神来之笔"。

## 1. 欧椋鸟方程（完整形式）

### 1.1 四个基本方程

```
∇·Φ = K · ρ          (1) 群体发散定律（类比）
∇×Φ = ∂T/∂t          (2) 群体旋度定律（类比）
∇·T = -∂Φ/∂t          (3) 群体守恒定律（类比）
∇×T = K · J           (4) 群体旋度-电流定律（类比）
```

**注意**：在离散 agent 系统中，这些方程应理解为**离散差分形式**：
```
Σ_i ΔΦ_i ≈ K · ρ
ΔΦ/Δt ≈ ∂T/∂t
Σ_i ΔT_i ≈ -ΔΦ/Δt
ΔT/Δt ≈ K · J
```

**变量定义**：
- **Φ**（Phi）：群体涌现能（全局标量，非场）
- **T**（Tau）：群体演化速率（标量 T = (1/N) Σ |v_i|，非矢量场）
- **K**（Kappa）：关键少数比（标量）
- **ρ**（Rho）：群体面密度（标量）
- **J**（J）：群体流（标量）

**算符定义**：
- **∇·**：在离散系统中理解为"空间求和" Σ_i
- **∇×**：在离散系统中理解为"时间差分" Δ/Δt
- **∂/∂t**：时间导数
- **∂/∂t**：时间偏导数

```
⎡Φ₁₁ Φ₁₂ Φ₁₃⎤   ⎡K₁⎤ ⎡R₁₁ R₁₂ R₁₃⎤ ⎡T₁₁ T₁₂ T₁₃⎤

⎣Φ₃₁ Φ₃₂ Φ₃₃⎦   ⎣K₃⎦ ⎣R₃₁ R₃₂ R₃₃⎦ ⎣T₃₁ T₃₂ T₃₃⎦
```
