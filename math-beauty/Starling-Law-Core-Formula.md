## 摘要

本文提出了类似于e=mc²的欧椋鸟群体动力学核心公式，用最简洁的数学表达揭示了大规模群体行为的本质规律。

---

## 1. 核心公式：欧椋鸟定律

### 1.1 第一定律：关键少数定律

```
Φ = K · R
```

**物理意义**：
群体涌现能 Φ 等于关键少数比 K 乘以平均相对关系密度 R。

**注意**：这里的 R 是**每对鸟的平均关系强度**（无量纲密度），不是所有关系的总和。详见严格推导文档。

### 1.2 第二定律：相对关系定律

```
∂Φ/∂t = -γ · Φ + K · R · T
```

**物理意义**：
群体涌现能的时间变化率等于自然衰减加上关键少数驱动的力函数。

**注意**：此方程为启发式形式，严格推导见 `Starling-Theory-Rigorous-Derivation.md` 第 3 章。

### 1.3 第三定律：时空变换定律

```
R_ij(t+Δt) = R_ij(t) + V_ij · Δt + ε · η
```

**物理意义**：
相对关系随时间演化，由速度项和随机扰动项决定。

---

## 2. 统一形式：欧椋鸟方程

### 2.1 工程实用形式

```
Φ = K · R · T
```

**物理意义**：
群体涌现能等于关键少数比乘以平均关系密度乘以群体演化速率。

**注意**：此为简化形式（α=1, β=1, C=0, Ω=1）。完整形式见严格推导文档第 4 章。

### 2.2 离散形式（适用于 agent 模拟）

```
Φ(t) = (1/N) · Σ_{i=1}^N K_i · R_i · T_i
```

其中 K_i 是 bird i 的控制系数（关键少数为 1，其他为 0），R_i 是 bird i 的平均关系强度，T_i 是 bird i 的速度模长。
